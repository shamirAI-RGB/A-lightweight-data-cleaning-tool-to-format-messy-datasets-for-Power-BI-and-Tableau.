# Simple Data Prep

![Status](https://img.shields.io/badge/status-active-success.svg)
![Python Version](https://img.shields.io/badge/python-3.8%2B-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

A lightweight, beginner-friendly data cleaning tool designed to format messy datasets before exporting them to visualization tools like Power BI and Tableau. 

## Features
* **Automated Cleaning:** Instantly removes null values and duplicates with minimal code.
* **E-commerce Ready:** Includes specialized scripts to clean raw sales reports from platforms like TikTok Shop and Shopee.
* **Beginner Friendly:** No complex configurations required. Just run the script and get clean data ready 
git clone https://github.com/shamirAI-RGB/simple-data-prep.git
cd simple-data-prep
pip install -r requirements.txt
